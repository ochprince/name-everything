# Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Vite’s default favicon with a hand-drawn SVG mark: white geometric `N` on a cyc→cobalt→rose cyclorama field.

**Architecture:** One static asset in `public/`, one `<link>` in `index.html`, delete the old Vite SVG. No runtime code, no font embedding.

**Tech Stack:** SVG, Vite static `public/` serving, existing DESIGN.md color tokens.

## Global Constraints

- Colors exactly: cobalt `#002FA7`, letter `#ffffff`
- Single file SVG only — no `.ico`, no apple-touch
- Do not embed web fonts; `N` must be a path
- README unchanged; MANIFEST may get one brief note

---

**Files:**
