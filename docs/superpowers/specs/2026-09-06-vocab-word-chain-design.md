# 词语接龙挑战设计（2026-09-06）

词汇记忆模块的检索/产出挑战：首尾字母接龙，词卡串成链。纯本地、无需 AI、可离线。

## 目标

把已学词汇变成可随时玩一局的检索练习：给定尾字母，从记忆里捞词、拼写出来。链越长越有成就感，冷门字母加分制造小惊喜；超时即结算，重开成本低。

## 决议

| 项 | 决定 |
|----|------|
| 入口 | 词汇记忆主界面（`/practice/pictures`）新增「词语接龙」入口 → `/practice/pictures/chain`（单局页） |
| 词库范围 | CET4 全量（已学/未学都可接——未学词接上顺带在图卡里接触一次）；起始词从已学词（strong/warm）按词频随机，为空则取词库高频词 |
| 接词方式 | 手动输入英文单词并提交（输入即考拼写），本地三道校验：① 首字母 = 当前尾字母（忽略大小写）② 词库词或真英文单词（词库外需离线词表核验，词表未就绪/离线时退回拼写启发式）③ 本局未用过；不通过提示具体原因、可重输 |
| 计时 | 每词 10 秒倒计时条（复用词汇记忆倒计时手感）；接上即重置；超时 = 本局结束 |
| 计分 | 每词 1 分；命中词库（有图片卡）的词 ×2——词库词即「稀有」，鼓励用学过的词；词库外真词 1 分 |
| 结束 | 超时或主动放弃 → 结算页：链长（词数）/ 总得分 / 是否刷新纪录 |
| 纪录 | localStorage `wordChain.best` = { length, score } |
| 美术/动效 | 全部后置；词卡链先做简单横排列表（词 + 小图，图走现有 CDN 图机制），链式插画、闪光、断链动效待美术阶段 |

## 一局流程

```
词汇记忆页 →「词语接龙」
  → 开局：抽起始词卡（词 + 图 + 中文）→ 高亮它的结尾字母为起点
  → 输入单词提交 → 本地校验
       ├─ 通过 → 节点加入链尾，尾字母更新为新词结尾字母，链 +1，得分累计（词库词 ×2），倒计时重置
       ├─ 不通过 → 提示（首字母不对 / 词库没有 / 本局用过）→ 重输
       └─ 超时 / 主动结束 → 结算
  → 结算页：链长 / 得分 / 纪录（最高链 + 最高分）→ 回词汇记忆页
```

## 关键实现挂点

- 词库校验：需全量目录（`ensurePictureWordsReady` 后建 word Set；首次进入若目录未就绪需等待，沿用已知边界）——图与词详情按需 `fetchPictureWordsByWords`（已有增量缓存）
- 起始词：读词汇 progress 的 strong/warm id 集 → 词频高者优先；空则回退词库高频词
- 倒计时：复用词汇记忆的倒计时 UI/循环模式（不引入新引擎）
- 纪录：localStorage `wordChain.best`
- 路由：`/practice/pictures/chain`；入口按钮放词汇记忆主界面

## 测试要点

- 三道校验各自触发与提示；大小写不敏感
- 词库词 ×2（词库外真词 1 分）；计时重置/超时结束
- 词库外节点无图卡：以首字母字块展示；词库节点带图/释义/「×2」标
- 词卡链顺序与尾字母更新正确
- 纪录读取/刷新（含并列、低分不覆盖）

## 后续可能（不在本期）

- 链的蛇形/回绕插画与断链动效
- 提示机制（卡住时可看首字母候选，扣分或限次）
- 接龙词自动进复习管道（接上的未学词 → 稍后复习）——需单独讨论，本期不做
