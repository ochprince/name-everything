# 挑战者模式设计（2026-09-06）

语法产出的独立挑战局：以「已过关知识点」为对手，自由造句、AI 判定，3 句合格击败一个知识点，波次递进。是举一反三门闩的"无限版"。

## 目标

给学完基础语法的学习者一个持续练习"自由产出"的场所——比举一反三更难（不再背靠某个关卡，结构随机、句句要过 AI 判定）、更游戏化（波次/连胜），无失败压力，只积累合格表达。

## 呈现：知识点 = 怪兽（用户定案，2026-09-06）

暂无美术插画，**不画怪兽、不用占位图**——以知识点本身作为"对手卡"（typography 排版，复用现有深色卡片语言）：

- 兽名 = 知识点中文名（大字，如「被动语态」）
- 归属 = 章节小字
- 习性 = 知识点 body 原文（它"要求"什么样的句子）
- 血槽 = 3 格句泡（第 N 句合格点亮第 N 格）

未来美术就绪时，仅在此卡片位叠加插画/动效，**流程与数据结构不变**。

## 决议

| 项 | 决定 |
|----|------|
| 入口 | 挑战 hub（`/practice/challenge`）新增第三入口「挑战者」；已开通 AI 且 ≥1 个语法关已过关才可进，否则锁定（复用关门图标 + 提示语义） |
| 结构池 | 仅 `passedLevelIds`（已过关的 level）随机抽取，本局内不重复；抽尽一轮后重洗继续（连胜持续累计） |
| 每只血量 | 3 句合格 |
| 判定 | 复用 `judgeProduceSentence`（举一反三同款 prompt：知识点 title/body + 本关例句对照反雷同 + 合格给 zh/comment），**追加约束「不得与本局已合格句子主干雷同」**；未开通 AI 判不了 → 入口锁定 |
| 不合格 | 显示 AI reason，可改写再交；不扣血、不扣次数 |
| 判定失败 | 超时/配额/网络 → 提示重试，不放行 |
| 失败/退出 | 无失败设计；header 返回 = 结束本局（≥1 句合格或 ≥1 只击败才进结算，否则直接退出） |
| 结算 | 本局击败 N 只 / 合格句总数 / 是否刷新最高连胜（localStorage `challenger.bestStreak`） |
| 候选沉淀 | 每句合格即 `recordProduceCandidate`（现有本机+远程候选管道，levelId = 该知识点所在关） |
| 美术/动效 | 全部后置；界面只复用现有组件与色块占位，语义动画（击败/断血）等美术阶段再议 |

## 一局流程

```
挑战 hub →「挑战者」入口
  → (校验 AI 开通 + 已过关 ≥1) → 开局页（最高连胜 + 「开始」）[可省，直接开局]
  → 抽一个已过关 level → 渲染「知识点卡 + 3 格句泡 + 造句输入（复用举一反三面板）」
  → 提交句子 → AI 判定
       ├─ 合格 → 句泡 +1 格，展示 AI zh/comment（通过态视图）→「下一句」
       │        句子实时入候选管道
       │        第 3 句合格 → 击败 →（下一知识点：波次 +1，池内去重随机）
       ├─ 不合格 → 展示 reason → 改写再交（循环）
       └─ 判定失败 → 提示重试（循环）
  → 任意时点返回 = 结束本局 → 结算页（击败数/合格句/纪录）→ 回挑战 hub
```

## 关键实现挂点

- 抽取：`grammarProgress.passedLevelIds` → `levelsForChapter` 全展开 → shuffle 去重取一只（局内 used 集合）
- 面板：复用 `ProduceGatePanel`（知识点卡替换现有 title/body 区布局，句泡新做，输入/提交/通过态/反馈原样）
- 判定与候选：`judgeProduceSentence`（prompt 增加本局去重行）+ `recordProduceCandidate`，levelId 取自抽中的关
- 纪录：localStorage，`challenger.bestStreak`（数字）
- 路由：`/practice/grammar/challenger`（单局页），hub 入口按钮
- AI 依赖与举一反三完全同套（allowlist 设备码 → ai_jobs → worker）

## 测试要点

- 结构池只含 passedLevelIds；抽怪局内不重复、抽尽重洗
- 判定合格 → 句泡递增、第 3 句结算击败、候选入库一次
- 不合格/判定失败不结算、可重交
- 纪录读取/刷新；入口锁定条件（未开通 AI / 无已过关）

## 后续可能（不在本期）

- 连续击败的节奏感（每只之间的小结算/加速）
- 知识点"兽卡"插画与击败动效
- 波次难度曲线（结构按教学序从前往后抽的权重）
