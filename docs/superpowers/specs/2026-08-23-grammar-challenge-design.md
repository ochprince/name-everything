# 语法挑战（Arcade）玩法设计

**日期：** 2026-08-23  
**状态：** 已批准并实现

## 背景

原「语法游戏」将已过关全部 playable 句子打乱为无限队列，句子库增长后单局过长、无明确胜利条件。

## 目标

- 每局固定最多 30 句，分组递进难度
- 池 ≥ 30 且 30/30 通关 → 奖杯 + 累计计数
- 池 < 30 全通 → 挑战成功文案，无奖杯
- 失败 → 记录本局得分，无奖杯
- 模块更名为「语法挑战」

## 核心规则

| 条件 | 结果 |
|------|------|
| 池 < 30，全通 | 「挑战成功」，无奖杯 |
| 池 ≥ 30，30/30 全通 | 「挑战成功」+ 奖杯，累计 +1 |
| 3 命耗尽 | 记录本局得分，无奖杯 |

- 每 5 句一组，组间下落时间递减（1.0 → 0.9 → 0.8 → 0.7 → 0.65 → 0.6）
- 组切换时 GSAP 浮层提示「第 N 组 · 速度提升」
- 分层抽样：每已过关关卡至少 1 句；关卡 > 30 时随机 30 关各 1 句；一局内不重复

## 数据

```ts
ArcadeRecord: { id, at, score, total, cleared }
GrammarProgress.arcadeTrophyCount  // 独立累计，不依赖 history 条数上限
```

旧历史记录迁移：`total` 默认 `score`，`cleared` 默认 `false`。

## UI

- Hub：累计奖杯、历史倒序、通关记录旁 `LevelPassTrophy`
- 进行中 header：`第 N 组 · 还剩 X 句`
- 首页磁贴：「语法挑战 · 30 句限时挑战，通关赢取奖杯」
